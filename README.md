# AO Accounts V3.3 — No VAT + Payment Editing

## أهم التعديلات
- بدون ضريبة نهائيًا.
- إضافة زر **إدارة السداد** لكل فاتورة.
- من إدارة السداد يمكن تعديل أي دفعة أو حذفها.
- تسجيل دفعة جديدة من نفس نافذة إدارة السداد.
- تحديث المسدد والمتبقي تلقائيًا بعد التعديل أو الحذف.
- تحسين قراءة البيانات القديمة من إصدارات AO Accounts السابقة.
- استمرار تعديل وحذف الفاتورة.
- استمرار المعاينة والطباعة PDF.

## ملاحظة عن البيانات
البيانات الحالية ما زالت محفوظة في LocalStorage في نفس المتصفح. هذه النسخة تحاول قراءة بيانات الإصدارات السابقة تلقائيًا، لكن إذا تم مسح بيانات الموقع من المتصفح فلن يمكن استرجاعها بدون قاعدة بيانات سحابية.
