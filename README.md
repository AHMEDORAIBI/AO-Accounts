# AO Accounts V3

نسخة V3 الجاهزة لـ GitHub Pages.

## الجديد
- تصميم فاتورة A4 احترافي بهوية AO.
- معاينة الفاتورة قبل الطباعة.
- طباعة أو حفظ PDF من نافذة الطباعة في المتصفح.
- عربي / English مع RTL / LTR.
- اتجاه كتابة تلقائي لاسم العميل والبيان والملاحظات.
- تسجيل أكثر من دفعة على الفاتورة.
- سجل الدفعات يظهر داخل الفاتورة.
- تعديل الفاتورة.
- حذف الفاتورة.
- ترحيل تلقائي قدر الإمكان لبيانات V1/V2 المخزنة في نفس المتصفح إلى V3.
- Dashboard: إجمالي الفواتير / المسدد / المتبقي.

## ملفات الرفع
ارفع الملفات التالية إلى جذر Repository:
- index.html
- styles.css
- app.js
- ao-logo.jpg
- README.md

ثم Commit changes. GitHub Pages سيعيد النشر تلقائياً.

## ملاحظة مهمة
البيانات ما زالت محفوظة داخل LocalStorage في المتصفح الحالي، وليست قاعدة بيانات سحابية بعد.
