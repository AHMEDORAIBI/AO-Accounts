# AO Accounts V3.4 — Official AO Letterhead

هذه النسخة تعتمد الهيدر/الورقة الرسمية المرسلة من المستخدم كخلفية كاملة للفاتورة A4.

## الجديد
- اعتماد ورقة AO الرسمية كاملة كخلفية للفاتورة:
  - الشعار أعلى الصفحة
  - الخط الأزرق/الذهبي
  - العلامة المائية الكبيرة
  - رقم الهاتف والإيميل
  - الشريط الذهبي السفلي
- إزالة الشعار المكرر والتذييل المكرر من تصميم الفاتورة.
- وضع بيانات الفاتورة داخل المساحة البيضاء المناسبة فوق الهوية.
- بدون ضريبة.
- تعديل وحذف الفاتورة.
- إدارة السداد: إضافة، تعديل، حذف.
- المسدد والمتبقي يتحدثان تلقائيًا.
- معاينة + طباعة / حفظ PDF.
- عربي / English.
