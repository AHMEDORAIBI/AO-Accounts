# AO Accounts

نسخة أولى خفيفة من نظام AO للفواتير والسداد والأرصدة والطباعة/PDF.

## الوظائف
- إنشاء فاتورة.
- رقم فاتورة تلقائي.
- تسجيل دفعات متعددة على الفاتورة.
- حساب المدفوع والمتبقي وحالة الفاتورة تلقائياً.
- Dashboard لإجمالي الفواتير والمسدد والمتبقي.
- بحث بالعميل أو رقم الفاتورة.
- طباعة فاتورة A4 أو حفظها PDF من نافذة الطباعة.

## التشغيل محلياً
افتح `index.html` مباشرة في المتصفح.

## النشر على GitHub Pages
1. أنشئ Repository جديداً في GitHub.
2. ارفع جميع الملفات مع مجلد `assets`.
3. من Settings > Pages اختر Deploy from a branch.
4. اختر branch `main` والمجلد `/root`.
5. افتح الرابط الذي يعطيك GitHub Pages.

## مهم قبل الاستخدام الفعلي
هذه النسخة تحفظ البيانات في `localStorage` داخل نفس المتصفح والجهاز، وهي مناسبة للمعاينة والنسخة الأولية فقط.

للاستخدام الحقيقي من أكثر من جهاز، نوصي في المرحلة التالية بربط المشروع بقاعدة بيانات مثل Supabase أو Firebase مع تسجيل دخول وصلاحيات، مع إبقاء الكود على GitHub.
