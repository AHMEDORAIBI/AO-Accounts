# AO Accounts V3.1

نسخة محسنة جاهزة لـ GitHub Pages.

## الجديد في V3.1
- إعادة تصميم الفاتورة A4 بشكل أكثر احترافية.
- تكبير الشعار وتحسين رأس الفاتورة.
- إبراز اسم العميل والحالة.
- قسم بيان مستقل وواضح.
- ملخص مالي منظم: المبلغ، الضريبة، الإجمالي، المسدد، المتبقي.
- تعديل الفاتورة وحذفها.
- منع تخفيض إجمالي الفاتورة لأقل من المبلغ المسدد.
- تعديل دفعة مسجلة.
- حذف دفعة مسجلة وإعادة احتساب الرصيد تلقائياً.
- جدول الدفعات داخل المعاينة والطباعة.
- إخفاء أزرار تعديل/حذف الدفعات في نسخة PDF المطبوعة.
- دعم العربية والإنجليزية واتجاه الكتابة التلقائي.
- ترحيل بيانات V2/V3 من LocalStorage قدر الإمكان.

## ملفات الرفع
ارفع الملفات التالية إلى جذر Repository واستبدل القديمة:
- index.html
- styles.css
- app.js
- ao-logo.jpg
- README.md

ثم Commit changes وانتظر إعادة نشر GitHub Pages.

## ملاحظة
البيانات ما زالت محفوظة داخل متصفح الجهاز عبر LocalStorage. قاعدة البيانات السحابية ستكون المرحلة التالية.
